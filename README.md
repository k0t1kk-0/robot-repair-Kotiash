### 05.10.2026
**Що зроблено:**
* Налаштовано сортування графіки через параметр `Custom Axis (0, 1, 0)` та коригування точок `Pivot` у спрайтів для коректного перекриття об'єктів у 2D-просторі[cite: 2, 3].
* Створено префаби елементів оточення та небезпечних ділянок `DamageZone` із налаштуванням `Tiled` для масштабування текстур[cite: 3].
* Інтегровано та налаштовано компонент `Rigidbody 2D` для робота (вимкнено вплив гравітації та зафіксовано кут повороту)[cite: 4].
* Переведено керування персонажем на метод `FixedUpdate` із застосуванням `MovePosition`, що усунуло дрижання кадру при зіткненнях зі стінами.
* Налаштовано систему колізій карти за допомогою `Tilemap Collider 2D` та `Composite Collider 2D`, а також прибрано колайдери з тайлів землі (`Collider Type = None`).
* Реалізовано додаткові завдання («More things to try»): урізноманітнено рівень декоративними об'єктами та побудовано смугу перешкод із зон шкоди для активного маневрування.
