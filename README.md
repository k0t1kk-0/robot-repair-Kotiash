### 26.11.2026 — Юніт 4: вороги і снаряди (Лабораторна робота №5)
**Що зроблено:**
* Створив префаб ворога `Enemy` (тригер-колайдер, `Rigidbody2D` без гравітації) і скрипт `EnemyController`: патруль за таймером (`changeTime`, `direction = -direction`), вибір осі через `vertical`, шкода на дотик через `OnTriggerEnter2D`.
* Анімації ворога: кліпи `EnemyLeft`, `EnemyRight` (Flip X), `EnemyFixed` (Samples = 4), Animator Controller з Blend Tree `2D Simple Directional` за параметрами `Move X` / `Move Y` і перехід у `EnemyFixed` по тригеру `Fixed`.
* Робот отримав Animator з контролером `Player`: `Look X`, `Look Y`, `Speed`, тригери `Hit` і `Launch`. Аркуш спрайтів робота перевів на PPU = 100, щоб анімований робот був того самого розміру, що й статичний.
* Снаряд `Projectile`: `AddForce`, постріл на клавішу C, шари `Character` і `Projectiles` із вимкненою колізією в Layer Collision Matrix. Влучання викликає `Fix()` — ворог зупиняється, грає анімацію полагодженого й більше не шкодить.

**More things to try (зроблено всі 4 пункти):**
1. Швидкий і повільний варіанти ворога — Prefab Variant `EnemyFast` (Speed 2, Change Time 1.5) і `EnemySlow` (Speed 0.7, Change Time 4).
2. Ворог, що випадково міняє вісь руху (`randomAxis`, `axisChangeChance`); після зміни осі він іде назад до точки старту, щоб не «розповзатися» по карті — `EnemyRandomAxis` на сцені.
3. Інший спосіб прибирати снаряди — таймер життя `lifeTime = 2 с`, як у невразливості.
4. Обмежений темп пострілів — `timeBetweenLaunches = 0.5 с`, поки C не діє.

**Що не вийшло або забрало найбільше часу:** аніматор у частини ворогів був «порожній» (`Animator is not playing an AnimatorController`) — префаб треба було перезберегти/переімпортувати після створення контролера.

**Що зрозумів про Animator, шари й Awake:** Animation — це кадри одного кліпу, а Animator — схема станів, яка вибирає кліп за параметрами. `Awake` снаряда виконується ще всередині `Instantiate`, тому `rigidbody2d` уже є, коли викликається `Launch`; у `Start` він був би `null`. Шари потрібні, бо снаряд народжується всередині колайдера робота — рушій просто не перевіряє пару Character × Projectiles.

**Які Speed і Change Time обрав:** базовий ворог 1 × 3 (маршрут 3 од., вистачає часу зреагувати новачкові), швидкий 2 × 1.5 (той самий маршрут, але треба цілитися наперед), повільний 0.7 × 4 — «легкий» ворог для розминки.

**Що робить мій снаряд з ворогом:** не знищує, а лагодить — вороги тут зламані машини, а робот їх ремонтує.

**Що робитиму далі:** юніт 5 — UI здоров'я, NPC і діалог.

### 26.11.2026 — Юніт 5: HUD, діалоги, ігровий цикл (Лабораторна робота №6)
**Що зроблено:**
* UI Toolkit: `GameUI.uxml` (рамка, портрет, смуга здоров'я `HealthBar` у `HealthBarContainer`), `NPCDialogue.uxml`, `EndScreen.uxml`; Panel Settings — Scale With Screen Size, 1920×1080.
* `UIHandler` — синглтон (`UIHandler.instance`): `SetHealthValue`, `DisplayDialogue`, `DisplayWinScreen`, `DisplayLoseScreen`. `PlayerController.ChangeHealth` оновлює смугу (`currentHealth / (float)maxHealth`).
* NPC: аркуш нарізано 2×2, кліп `NPC` (4 кадри/с), шар `NPC`, колайдер на нижню половину. Робот шукає NPC променем `Physics2D.Raycast` довжиною 1.5 у бік погляду; над NPC з'являється бульбашка з X, X показує репліку на 4 с.
* `GameManager`: здоров'я 0 → екран поразки, усі вороги полагоджені → екран перемоги; через 3 с `SceneManager.LoadScene`. `MainScene` додана в список сцен збірки.

**More things to try (зроблено 3 пункти):**
1. Другий NPC `NPC_Mechanic` зі своєю реплікою — текст у полі `dialogueText`, `DisplayDialogue(string)` пише його в Label.
2. Лічильник «Полагоджено x / N» у HUD — `UIHandler.UpdateRobotCounter()`, його викликає `Fix()` ворога.
3. Прапорець `gameOver` у `GameManager` — `Invoke` більше не ставиться в чергу щокадру.

**Що зрозумів:** синглтон — один екземпляр, доступний звідусіль через static-властивість, тому `PlayerController` не потребує посилання в Inspector. Для NPC — промінь, а не тригер, бо важливо, щоб робот *дивився* на NPC. `(float)` потрібен, бо ділення цілих дає 0 або 1.

**Що каже мій NPC:** пояснює мету — лагодити роботів шестернями; механік підказує, як цілитися у швидкого робота.

**Умови перемоги й поразки:** усіх ворогів полагоджено — перемога; здоров'я 0 — поразка; в обох випадках рівень починається знову.
