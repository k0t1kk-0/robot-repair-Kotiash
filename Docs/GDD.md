# GDD — Robot Repair: Затоплений склад

**Версія документа:** 1.0 (відповідає релізу `v1.0`, збірка `RobotRepair-v1.0-windows`)
**Автор:** Kotiash · **Рушій:** Unity 6.3 (URP 2D) · **Платформа:** Windows

## Ігровий процес
Вертикальний зріз (60–120 с) top-down пригоди. Робот проходить затоплений склад із трьох ділянок і лагодить зламаних роботів-вантажників, стріляючи в них шестернями. Ворогів не знищують — їх лагодять.

**Core loop:** рух → читання маршруту ворога → постріл → ухилення / пошук аптечки.
**Перемога:** усіх ворогів полагоджено (лічильник «Полагоджено x / 5»). **Поразка:** здоров'я 0. В обох випадках через 3 с рівень починається знову.

## Елементи гравця
| Дія | Клавіша | Числа |
|-----|---------|-------|
| рух | стрілки / WASD | speed 3 |
| постріл шестернею | C | сила 300, пауза 0.5 с, снаряд живе 2 с |
| розмова з NPC | X (промінь 1.5 од. у бік погляду) | репліка 4 с |
| здоров'я | — | 5, невразливість 2 с після удару |

## Вороги та об'єкти
| Об'єкт | Параметри |
|--------|-----------|
| Enemy | Speed 1, Change Time 3, шкода 1 за дотик |
| EnemySlow (варіант) | 0.7 × 4 |
| EnemyFast (варіант) | 2 × 1.5, помаранчевий колір загрози |
| DamageZone | damage 1 (OnTriggerStay2D) |
| CollectibleHealth / _Big | amount 1 / 2 |
| **Твіст:** TimedSwitchDoor | плита відчиняє двері до 3-ї ділянки на `openTime` = 4 с, залишок часу на HUD |

## Інтерфейс користувача
* **HUD (non-diegetic):** смуга здоров'я з портретом (лівий верх), «Полагоджено x / N» (правий верх), таймер дверей (під лічильником, лише коли двері відчинені).
* **Spatial:** бульбашка «Press X» над NPC, коли робот дивиться на нього.
* **Meta:** стартовий екран (назва, мета, керування, кнопка «Грати»/Enter), екрани перемоги й поразки з плавною появою (opacity, 1 с).

## Зворотний зв'язок
удар — звук `PlayerHit` + червоне блимання робота + анімація Hit + смуга; підбирання — звук `Collectible` + смуга; постріл — звук `Projectile`; полагодження — звук `EnemyFix` + анімація + лічильник. Один звук на подію (шкода щокадру відсікається невразливістю).

## Дизайн рівня (як є в грі)
1. **Знайомство:** старт, NPC з метою і підказкою про плиту, один повільний ворог.
2. **Практика:** два звичайні вороги, зона шкоди, аптечка після них; плита-перемикач перед дверима.
3. **Перевірка:** двері з таймером, велика аптечка, два швидкі помаранчеві вороги, NPC-механік з порадою.

**Текст рівня:** NPC — «Склад затопило, а роботи-вантажники зламалися. Полагодь усіх шестернями (C)! Двері до останньої зали відчиняє плита — встигни за 4 секунди.» Механік — підказка про швидкого робота.

## Системні вимоги
Windows 10/11 x64, будь-яка відеокарта з DirectX 11. Розпакувати zip і запустити `RobotRepair-ZatoplenyiSklad.exe` (віконний режим 1280×720). Unity не потрібен.

## Ризики й альтернативи
* Вороги-тригери проходять крізь стіни — маршрути підібрано так, щоб лежати на вільному місці.
* Снаряд зупиняється об NPC — механіка в 3-й ділянці треба обходити (залишено як є).
* Стартовий екран зроблено кодом у `UIHandler`, а не окремим UXML — відкладено.
