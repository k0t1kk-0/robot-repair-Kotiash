# План рівня MyLevel (1 клітинка = 1 тайл, ділянка = 24 тайли)

```
|---- 1. Знайомство ----|---- 2. Практика -------|---- 3. Перевірка ------|
| NPC                   |   B <------->           |  Ш <----->  (помаранч.)|
|        C              |  [XX]      +            =     + (велика)  NPC-мех |
|                B      ==       B                =  Ш <----->             |
|                ↕      |         ↕               |                       |
C — старт   NPC — каже мету   B — ворог   Ш — EnemyFast   [XX] — зона шкоди
+ — аптечка   == — прохід між ділянками   ↕ / <--> — маршрут ворога
```

1. **Знайомство:** один повільний ворог (`EnemySlow`, 0.7 × 4), NPC біля старту каже мету.
2. **Практика:** два звичайні вороги (1 × 3) і зона шкоди, аптечка — після них.
3. **Перевірка:** два швидкі помаранчеві варіанти (2 × 1.5), велика аптечка на вході, NPC-механік з підказкою.

## Плейтест самому собі
| Спроба | Час | Ударів отримано | Здоров'я на перемозі |
|--------|-----|-----------------|----------------------|
| 1 | ~2:00 | 0 | 5/5 |

Висновок: рівень прохідний; на першій спробі 5/5 — легкувато, тому швидкі вороги в 3-й ділянці стоять на двох рядах, щоб змусити маневрувати.
